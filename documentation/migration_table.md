# Document split: migration table

The 93-page technical document was doing two jobs — explaining the
engineering and computational system, and presenting this project's
results. This table records how each piece was routed, and is the plan of
record for the split.

**Governing rule.** Methodology stays; findings move. Where a section
contains both — and several do — the physical reasoning stays in the
technical document and the numbers move to the report, with a
cross-reference in each direction. Nothing is deleted.

## What must not happen

- No methodology removed from the technical document without a
  destination.
- No result lost: every moved section lands somewhere in the report.
- No duplication: the report explains only the theory needed to defend
  its results, and points to the technical document for the rest.
- No number typed by hand where a saved result exists.
